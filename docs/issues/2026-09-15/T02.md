# [TRACE PoC] Python計算サービスと非同期ジョブの実行基盤を作る

GitHub公開済み: [#4](https://github.com/romashito-ueda/enegaeru_biz_poc/issues/4)

## 目的
ネイティブのPySAMをUIから分離し、重い計算でも編集・再試行できる実行経路を用意する。

## 共通前提
対象は産業用太陽光・蓄電池を提案する販売施工店/EPC向けTRACE PoC。モック・固定値を許容し、計算・判断の整合性を検証する。契約電力/基本料金削減は対象外。既存のローカルReact/Vinext PoCを[T00](T00.md)で取り込み、Python/PySAMを接続する。実データ調達は初期PoCのブロッカーにしない。

## 実装範囲
- Python 3.12と検証済みnlr-pysam==8.0.0、numpy-financial==1.0.0を起点に、独立環境・固定依存・ライセンス表示・起動手順を整備する。既存work/engine-packagesへの暗黙依存をなくす。
- ローカルPython APIにPOST /jobs、GET /jobs/{id}、キャンセル、healthを実装する。queued/running/succeeded/failed/cancelled、進捗、入力hash、モデル版、計算対象範囲を返す。
- CPU計算をHTTPイベントループから分離する。PoCは原則1ワーカー、キュー長・候補数・入力サイズ・実行時間・保持件数に上限を置く。
- 同一入力の再利用、連打の重複抑止、期限切れキャッシュ、例外、キャンセル後の結果破棄を扱う。計算失敗を仮の成功結果へ置換しない。
- React/Vinext側から開発時proxy等で呼ぶ。Python/SSCをブラウザや既存Workersバンドル内で実行しない。PoCのジョブはローカルのみとし、再起動時の消失を明示する。

## 完了条件
- [ ] 文書化したクリーンなローカル環境からUIとPython APIを起動でき、外部データAPIキーなしで契約fixtureを送信できる。
- [ ] 遅い評価用workerでもAPIが応答し、進捗確認・キャンセル・再試行ができる。
- [ ] 同一hashの重複要求が同時に何件も走らず、異なるモデル版・期間・前提の結果をキャッシュ混用しない。
- [ ] 停止・異常終了・時間上限・キュー超過を区別したエラーが返り、内部詳細をそのまま利用者画面へ露出しない。
- [ ] T03/T04の実モデルを同じworker契約で接続できる。検証用stubの結果は検証用として識別される。

## 検証

## 対象外
